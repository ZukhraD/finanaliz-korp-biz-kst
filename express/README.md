# Экспресс-анализ для КМ

Предварительная оценка клиента клиентским менеджером: подходит ли клиент для финансирования — ещё до сбора полного пакета документов.
Регистрация не нужна. Данные хранятся **только в браузере** (localStorage) и никуда не отправляются: сетевые запросы запрещены политикой безопасности (CSP). Перенос клиента на другой компьютер — кнопка «Сохранить в файл» (.json); такие файлы в репозиторий не загружайте.

## Стиль
Фирменная палитра ОФКК: белый 70 %, лазурно-синий #023DFF 10 %, лайм #00BB00 10 %, графит #272727 5 %, платина #E5E4E2 5 %. Форма плашек — скругление с прямым нижним левым углом.
Шрифты: заголовки — Futura PT, если она установлена на компьютере, иначе встроенный Jost (свободный аналог Futura); основной — Roboto (встроен); системные уточнения — Verdana. Jost и Roboto — лицензия SIL OFL (`src/fonts/OFL-*.txt`), встроены в подмножестве латиница + кириллица.

## Разделы
1. **Карточка клиента** — запрашиваемые условия: клиент, продукт, цель, сумма, срок, ставка, погашение, льготный период, примерный взнос по действующим кредитам в месяц. Для **овердрафта** — срок транша и расчёт лимита по поступлениям за месяцы (см. ниже).
2. **Финансовая отчётность** — до 4 периодов; **период определяется сам по датам в шапке документа** («на 31.12.2025», «по состоянию на 30.09.2026», «за 2025 год», «за 9 месяцев 2026», «за период с … по …», 1 квартал / полугодие, казахские названия месяцев) — нужный период находится или создаётся, колонка «на начало / за прошлый год» идёт в прошлый год; если даты нет — сайт спрашивает, в какой период загрузить; загрузка баланса, ОПиУ, ДДС и налоговых деклараций 100.00 / 910.00 / 300.00 — **Excel, PDF с текстом, PDF-скан или фото (JPG, PNG)**; тип документа определяется сам. Или ручной ввод. Всё в тыс. тг.
3. **Анализ** — вывод и показатели простым языком; для кредита — сколько можно дать по доходам, для овердрафта — расчётный лимит.
4. **Заключение** — готовый документ без редактирования, обновляется сам; копировать текст, печать / PDF.

Кнопка **«Пример для заполнения»** — вымышленная компания с заполненными данными (в ней можно переключить продукт на «Овердрафт»).

## Телефон, планшет, компьютер
При входе сайт определяет устройство (ширина экрана, сенсорное управление, модель — в т.ч. iPad в режиме «как компьютер») и ставит `data-device` = `phone` / `tablet` / `desktop`; при повороте экрана и изменении окна — заново.
- **Телефон**: нижняя панель разделов, одна колонка, поля и кнопки под палец (шрифт полей 16 px — без увеличения в iOS), таблицы листаются вбок с закреплённой первой колонкой, загрузка «выбрать файл или сфотографировать», у заключения — «Поделиться», диалоги снизу.
- **Планшет**: разделы вкладками сверху, поля и показатели в две колонки.
- **Компьютер**: боковое меню, три колонки.

## Управленческая отчётность (клиенты без бухгалтерии)
Шаблон банка с листами «Баланс ГГГГ» (АКТИВ / ПАССИВ на две даты, например 01.01.2025 и 01.01.2026) и «ОПиУ ГГГГ» (по месяцам), в тенге, без кодов строк — распознаётся сам по названиям строк.
- Баланс: дата 01.01.2026 = на конец 2025 года, 01.10.2026 = на 30.09.2026. Касса + расчётный счёт + сбережения → деньги; ТМЗ и товары в пути → запасы; оборудование, транспорт, недвижимость, НМА, инвестиции → основные средства; товарный кредит и краткосрочная кредиторка → кредиторская задолженность; кредиты банков и частные займы → кредиты (до / свыше года); капитал = уставный + нераспределённая прибыль (если итоги не пересчитаны — активы минус обязательства).
- ОПиУ: суммы за месяцы с начала года по последний заполненный → период; выручка, себестоимость, расходы по бизнесу (амортизация — отдельно), **расходы вне бизнеса (семья) минус доходы вне бизнеса** — отдельная строка, она уменьшает деньги на платежи по кредитам. «Взнос по действующим кредитам» (среднее в месяц) переносится в «Карточку», если там пусто.

## Сканы
PDF без текстового слоя и фото документов распознаются **в браузере** движком Tesseract (модель `rus`, tessdata_fast) — файлы никуда не отправляются.
Движок и модель (`ocr/`, ~8 МБ) загружаются с сайта при первом скане и кэшируются браузером. Из PDF берётся картинка страницы: JPEG, Flate/LZW, чёрно-белые CCITT G3/G4 (типично для МФУ). JPEG 2000 и JBIG2 не поддерживаются — такой PDF нужно пересохранить или отсканировать в цвете / оттенках серого. Распознавание работает только на сайте, не в файле, открытом с компьютера.
Лицензии: tesseract.js-core и tessdata — Apache 2.0 (`ocr/LICENSE-*.txt`).

## Овердрафт (сокращённо, по правилам основного сайта)
- Лимит = 40 % среднемесячных **очищенных** поступлений за 6 полных месяцев до месяца заявки (при сезонности — 12) отдельно по нашему банку и по другим банкам (не более 2); при транше до 90 дней — не более 100 млн тг.
- Доля одного покупателя больше 60 % — его поступления учитываются не более 60 % (поступления уменьшаются на 40 % × доля).
- **Выписки по счетам** (PDF с текстом, PDF-скан, Excel) загружаются в блоке овердрафта с отметкой «наш банк / другой банк». Из кредитовых оборотов исключаются: 1) выдача кредитов; 2) конвертация — продажа валюты с валютных счетов; 3) поступления с других счетов клиента; 4) возврат платёжных документов; 5) финансовая помощь связанных компаний; 6) кредиты (займы) от учредителей; 7) взносы наличными, кроме инкассации, банкоматов Cash-in и POS; 8) государственные субсидии. Штрафы, пени, вознаграждение и страховые выплаты не исключаются. Распознавание — по назначению платежа, КНП и БИН; любую операцию можно вручную вернуть в расчёт или исключить. По выпискам сами считаются обороты по месяцам, число покупателей, доля крупнейшего (ограничение 60 % — по каждому покупателю), число других банков и частота поступлений (не реже 3 раз в месяц). Месяцы без выписки в расчёт не попадают. Для валютного счёта нужно указать курс.
- Проверки: срок деятельности ≥ 6 мес. (12 — при сезонности или транше 90 дней), поступления каждый месяц, ≥ 3 покупателей, доля одного ≤ 60 %, ≤ 2 других банков, транш 90 дней не для строительства и сельского хозяйства, срок линии ≤ 36 мес., сумма ≤ лимита.

## Расчёты
- Заработок в месяц = (EBITDA − КПН) / 12; EBITDA = выручка − себестоимость − расходы периода + амортизация (без амортизации — осторожная оценка).
- Платёж по новому кредиту: цель **«Пополнение оборотных средств»** — в нагрузке только проценты (сумма × ставка в год, в месяц — 1/12); остальные цели (основные средства, инвестиции, рефинансирование, контракт) — по графику погашения (аннуитет / дифференцированный / в конце срока); овердрафт — только проценты.
- Покрытие платежей (DSCR) = заработок в месяц / (взнос по действующим кредитам + платёж по новому кредиту).
- Максимальная сумма — при которой DSCR = 1,25 на тех же сроке, ставке и способе погашения.
- Неполный год пересчитывается в годовой (× 12 / месяцев).
- Пороги — объект `NORM` в `src/ex2.js`; овердрафт — `odCalc` / `odChecks` там же.
