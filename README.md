# Финансовый анализ — объединённый сайт ОФКК Костанай

Один сайт «Финансовый анализ корпоративных клиентов. Костанай», на главной странице две кнопки:

| Кнопка | Адрес | Папка с исходниками |
|---|---|---|
| 1. Экспресс анализ (для клиентского менеджера) | `/express/` | `express/` |
| 2. Финансовый анализ (для кредитного менеджера) | `/finanaliz/` | `finanaliz/` |

Главная страница — `index.html` в корне (исходники в `hub/`). В каждом из двух сайтов есть ссылка «← На главную».
Серверные функции (`api/cloud.js` — облачная база, `api/prg.js` — подтягивание по БИН) общие и нужны только «Финансовому анализу».

## Язык: RUS / KAZ
Переключатель есть на главной и в обоих сайтах; выбор запоминается в браузере (ключ `finkz.lang`) и общий для всех трёх страниц.
- Главная: тексты на казахском — в `hub/build.py` (словарь `KZ`).
- Финансовый анализ: `finanaliz/i18n/kz*.json`.
- Экспресс анализ: `express/i18n/kz.json` (ключ — русская фраза, значение — перевод; числа в фразе заменяются на `{0}`, `{1}`…).
  Перевод сделан автоматически, терминологию стоит проверить специалисту; правки вносятся в словарь, затем `python3 build.py`.

## Как править каждый сайт отдельно
Сайты не зависят друг от друга: у каждого свои исходники, своя сборка, свои настройки безопасности.
- Финансовый анализ: правки в `finanaliz/src/` и `finanaliz/i18n/`, затем `cd finanaliz && python3 build.py` (нужен `fontTools`).
  Подробное описание — `finanaliz/README.md`.
- Экспресс анализ: правки в `express/src/`, затем `cd express && python3 build.py`. Подробное описание — `express/README.md`.
- Главная: правки в `hub/`, затем из корня `python3 hub/build.py`.

Собранные `index.html` лежат в репозитории — Vercel публикует их как есть, сборка на Vercel не нужна.

## Безопасность (vercel.json)
У каждого раздела своя политика безопасности, они не смешиваются: главной страницей и «Экспресс анализом» сеть не используется
(кроме загрузки собственных файлов сайта); «Финансовый анализ» дополнительно обращается к `/api/*` и по кнопке к Gemini.
При добавлении новых возможностей правьте только блок нужного раздела в `vercel.json`.

## Данные между сайтами
Оба сайта открываются с одного адреса, поэтому видят одно и то же хранилище браузера, а ключи у них разные:
`finkz.clients.v1` (Финансовый анализ) и `finkz.express.v1` (Экспресс анализ) — данные не перемешиваются.
Когда понадобится подтянуть данные клиента из одного сайта в другой — это делается отдельной доработкой, по запросу.

## Публикация на Vercel
Add New → Project → Import этого репозитория → Framework Preset **Other**, Build Command пусто, Output Directory `.` → Deploy.
Для облачной базы «Финансового анализа» в проект нужно подключить то же хранилище Upstash Redis (Storage) и при необходимости переменную `INVITE_CODE`
(см. раздел «Облачная база» в `finanaliz/README.md`). Если подключить ту же базу, что у старого сайта, учётные записи сотрудников сохранятся.

Данные клиентов в браузере привязаны к адресу сайта: на новом адресе локальные клиенты старых сайтов не появятся сами —
их переносят через «Сохранить файл клиента» / «Открыть файл».
